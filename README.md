# Walkabout

A Python program to simulate and visualize a random walk on a two-dimensional grid.

-   The walker starts at the center of the grid.
-   Each time step, it moves north, south, east, or west with equal probability.
-   It stops moving when it reaches the edge of the grid.
-   The result is a count of the number of times it occupied each grid cell.
-   The program creates a plot to display this.
